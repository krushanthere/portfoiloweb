# Contributing to Krushanta's Portfolio

Thank you for your interest in contributing to this project!

## Development Setup

1. **Fork and clone the repository:**
   ```bash
   git clone https://github.com/krushanthere/rpor.git
   cd rpor
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Verify production build:**
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Ensure your code passes TypeScript typechecks and ESLint checks (`npm run lint`).
- Keep commit messages clear, concise, and descriptive.
- Open a PR against the `main` branch with a clear summary of your changes.

## Code Style & Conventions

- **Next.js App Router** with React 19 and TypeScript.
- **Tailwind CSS v4** for styling and animations.
- **Three.js / React Three Fiber** for 3D canvases and shaders.
- **Motion / GSAP** for physics-based and timeline animations.
