## 🌌 Overview

This repository contains the personal portfolio and creative web platform for **Krushanta Podha**. Built with **Next.js 16**, **React 19**, **Three.js / React Three Fiber**, and **Tailwind CSS v4**, the site unites WebGL graphics, procedural particle simulations, dynamic typography, and generative Web Audio synthesis in an obsidian minimalist aesthetic.

## ✨ Features

- **🚀 3D Wormhole Preloader (`WormholePreloader`)**: Interactive canvas hyperspace tunnel with Web Audio frequency sweeps and a cybernetic telemetry HUD.
- **🖐️ The Creation of Adam 3D ASCII & Particle Hands (`HandSphereSection`)**: Dynamic point-cloud & glyph reconstruction of Michelangelo's *The Creation of Adam* with custom GLSL shaders.
- **✨ Interactive Glitter Warp Background (`GlitterWarp`)**: Fullscreen interactive particle starfield responsive to cursor velocity and scroll physics.
- **🪐 3D Quote Sphere & Node Graph (`QuoteSphere` / `QuoteNodeGraph`)**: Revolving 3D sphere and connected particle graph mapping philosophy, ideas, and engineering maxims.
- **🎵 Minimalist Vinyl Disc Player (`DiscPlayer` / `/player`)**: Interactive spinning record player with realistic vinyl groove reflections and global audio playback.
- **⚡ Obsidian Dark Aesthetic**: Deep pure black (`#000000`) theme with glassmorphism overlays and motion transitions powered by Framer Motion & GSAP.

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/krushanthere/rpor.git
cd rpor

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying Your Website with GitHub

This repository is pre-configured for automated deployment directly to **GitHub Pages** (or **Vercel**):

### Option 1: GitHub Pages (Directly on GitHub)
1. Push your repository to GitHub.
2. In your GitHub repository, go to **Settings** ➔ **Pages**.
3. Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
4. Every push to the `main` branch will automatically build and deploy your site live to `<username>.github.io/<repo-name>`.

### Option 2: Custom Domain via Vercel / Cloudflare
1. Connect this GitHub repository to [Vercel](https://vercel.com) or [Cloudflare Pages](https://pages.cloudflare.com).
2. Connect your custom domain (e.g., `krushanta.dev`).
3. Deployments trigger automatically on every git commit.
